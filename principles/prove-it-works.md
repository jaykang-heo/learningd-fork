# Prove it works

Imported from pstack. A claim is finished when evidence exists that would have
caught it being wrong.

- Code that appears in the lesson runs, against declared cases, in this run.
- A gate passes because its check ran on these exact bytes, not because it passed
  on an earlier draft.
- "I reviewed it and it looks right" is a verdict only when the reviewer is
  named and the verdict is recorded.
- A receipt is never edited by hand. If it is wrong, rerun the gate.
