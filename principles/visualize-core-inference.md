# Visualize the core inference

Coverage of core inference scenes by a substantive visual is 100%, not a target
(spec I7).

A "substantive" visual shows the actual objects and their relation. A decorative
icon, a stock illustration or a box-and-arrow restatement of the heading is not
substantive and must not be marked as one.

If the inference is a change - a transform, a movement, a state transition, an
inverse mapping - it needs a dynamic or hybrid visual. A static picture of the
before and the after leaves the change itself to the reader.
