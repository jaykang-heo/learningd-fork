# One scene, one message

A scene carries exactly one `primary_message`: one sentence a learner could
repeat afterwards.

If a scene needs "and also", it is two scenes. A three-item list is not a
message; it is an outline that has not been thought through yet.

The same rule applies to a visual: one visual, one primary job (spec 25.4). A
diagram that proves correctness *and* compares complexity *and* introduces
notation teaches none of them.
