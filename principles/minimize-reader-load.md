# Minimize reader load

Imported from pstack. Every sentence the reader must hold in working memory is a
cost the artifact has to earn.

- Put the relation on screen before explaining it in prose.
- Do not make the reader simulate state changes mentally; show the trace.
- Cut a sentence that only restates the previous one in different words.
- Length is not depth. The anti-padding ceiling exists because a longer document
  is the easiest way to fake one.
